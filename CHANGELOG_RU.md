# История изменений

## 0.6.6-beta — 2026-08-28
### Hotfix — 2026-08-29

- Исправлено устаревшее отображение версии: runtime-поверхности теперь используют установленную пакетную версию.
- Проверка связи со Spoolman отделена от назначения катушек слотам IFS: состояние `0/4` больше не даёт ложный offline.
- Синхронизация и health-monitor используют единый статус Spoolman от Moonraker; опрос остаётся малонагруженным и не зависит от назначений.


### Добавлено

- Плагин переведён на штатную Git-модель Z-Mod: постоянный checkout хранится в `mod_data/plugins/ad5x_ifs_spoolman`.
- После первичной SSH-установки обновления доступны через Moonraker/Fluidd Update Manager без повторного запуска установщика.
- Добавлены `ad5x_ifs_spoolman.cfg`, корневой `uninstall.sh` и управляемая регистрация `[update_manager ad5x_ifs_spoolman]`.
- Существующая raw-file установка мигрирует через транзакционный `update.sh` с сохранением `config.json`, `assignments.json`, `power_on.sh` и `user.moonraker.conf`.
- Обновление отключённого runtime не включает его обратно автоматически.

### Исправлено

- Runtime-версия backend теперь берётся из package `VERSION`, поэтому API и пакет показывают одну и ту же версию.
- `status.sh` корректно определяет нативную интеграцию Fluidd и отдельно проверяет отсутствие legacy-инъекции.
- Health-gate обновления больше не зависит от урезанного `wget`: используется Python Moonraker и `urllib.request` с проверкой JSON `application`.
- Продакшен-линия следует `release/standalone-0.6.x` через Moonraker `channel: dev`. Это сделано намеренно: Z-Mod для `stable` выполняет generic reset к глобально последнему Git-тегу, а в репозитории есть отдельный тег совместимости Fluidd.

### Проверка на реальном AD5X

- Полный Git-update путь проверен на реальном принтере до и после перехода на Z-Mod `1.7.3-1`.
- Проверены `git fetch/pull -> update.sh -> runtime apply -> health gate`, сохранение назначений катушек и Spoolman sync.
- После настоящего cold boot Z-Mod `1.7.3-1` плагин автоматически поднялся, Moonraker снова зарегистрировал updater, Fluidd обнаружил следующее обновление и обновление прошло успешно.

## 0.6.5-beta — 2026-08-28

### Добавлено

- Нативная Vue/Vuetify-карточка Fluidd вместо основной legacy DOM-инъекции.
- Автоматическая совместимость с официальной линией `ghzserg/fluidd`; текущая проверенная сборка — Fluidd `v1.37.4`, patch revision 4.
- Legacy-инъекция сохранена только как fallback и автоматически очищается при успешной нативной интеграции.

### Проверка на реальном AD5X

- После перезагрузки принтера backend автоматически поднялся, Fluidd показал ровно одну нативную карточку `AD5X IFS Spoolman`.

## 0.6.4-beta — 2026-08-27

### Исправлено

- Добавлен самостоятельный автозапуск через штатный `mod_data/power_on.sh` Z-Mod; существующий пользовательский код сохраняется, повторная установка не создаёт дубликаты.
- Устранена гонка старта: wrapper ждёт появления Moonraker до входа в его chroot.
- PID-файл больше не считается достаточным доказательством живого backend: проверяется командная строка процесса, восстанавливается потерянный PID-файл и предотвращаются дубли.
- `stop.sh` больше не может завершить посторонний процесс после повторного использования старого PID.
- `status.sh` теперь проверяет boot-hook, PID ownership, дубликаты backend, API, все компоненты Fluidd и показывает boot/event logs.
- Удаление очищает весь набор Fluidd-инъекций, включая dashboard/legacy controls, и удаляет только собственный блок из `power_on.sh`.
- Изменение `Fluidd/index.html` при установке и удалении выполняется атомарно.
- Установщик закреплён за отдельной maintenance-линией `release/standalone-0.6.x`, а не за экспериментальным `main`.
- Исправлен первый запуск backend без `config.json`: helper атомарной записи теперь объявлен до использования.
- Добавлен явный импорт `urllib.parse` вместо зависимости от побочного поведения импорта.
- Убраны устаревшие версии `0.2.2`/`0.1` из встроенного UI и HTTP server metadata.
- Синхронизированы package manifest, документация и набор файлов flattened installer.

### Версии

- Пакет и служебные скрипты: `0.6.4-beta`.
- Backend: `0.5.1-beta`.

## 0.6.0-beta — 2026-07-17

### Добавлено

- Скрипты установки, обновления, проверки состояния и удаления.
- Сохранение пользовательских данных при обновлении и обычном удалении.
- Автоматический откат обновления при ошибке запуска или health-check.
- Очистка старых файлов интеграции Fluidd и отдельный uninstaller.
- Структура публичного репозитория и примеры конфигурации.

### Backend 0.5.0-beta

- Структурированный журнал событий с ротацией.
- Время работы и диагностика отдельных компонентов.
- Счётчики и временные метки синхронизации.

### Backend 0.4.0-beta

- Подтверждение переключения несколькими чтениями.
- Повторные попытки и cooldown.
- Пропуск лишнего переключения уже активной катушки.
